## 🗂 关于这个仓库

本仓库存放的是 **Hexo 生成后的静态站点文件**（`index.html`、`css/`、`js/`、`posts/`、`medias/` 等），由 GitHub Pages 直接托管。

`README.md` 放在 `source/` 下，并已在 `_config.yml` 的 `skip_render` 中声明，因此 `hexo g` 会把它原样复制到 `public/`，`hexo d` 再带入仓库。它不会被渲染成文章或页面，也不进入导航，新增或修改不会影响博客访问。

注意：`hexo d` 每次会清空并重建 `.deploy_git`，所以 README 必须以 `source/README.md` 为准。

## 🔧 技术栈

| 组件 | 说明 |
| :--- | :--- |
| Hexo 5.3.0 | 静态博客框架 |
| itsNeko | 基于 Matery 魔改的站点主题 |
| GitHub Pages | 站点托管 |
| tagsnet / search / sitemap | 关系网 · 搜索 · 站点地图 |
| abbrlink / wordcount / aplayer | 短链接 · 字数统计 · 播放器 |

本地预览与部署（在源码工程根目录执行）：

```bash
hexo clean && hexo generate && hexo net && hexo server
hexo clean && hexo generate && hexo net && hexo deploy
```
